🌱 Agrisense

Smart Irrigation System

Using Arduino UNO + Soil Moisture Sensor

Soil Status: Checking...

Motor: OFF

How it Works

1. Sensor checks soil moisture
2. If soil is DRY - Motor TURNS ON
3. If soil is WET - Motor TURNS OFF
4. Saves Water, Electricity & Time

Components: Arduino UNO, Soil Moisture Sensor, Relay, Water Pump, Jumper Wires
